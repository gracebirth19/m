# Mars Class / The Announcement

A fictional announcement-day simulation starring Meira Berlow. NASA introduces its first Mars astronaut class, including Meira, the only woman selected. The class trains for a lunar expedition in 2046 ahead of a future crewed Mars landing.

## Play locally

Unzip the folder and open `index.html` in your browser. You can also serve the folder with `python3 -m http.server 8000` and visit `http://localhost:8000`. Serving over HTTP gives the app a consistent browser storage origin.

Switch between X, Instagram, Messages, and the Newsroom. New story events arrive over roughly three minutes at normal speed. You can reply, like, repost, bookmark, follow, or send a post to a contact inside the simulation. Write your own posts and look for replies. Use Settings to pause, advance, speed up, or restart the announcement.

## Deploy to GitHub Pages

1. Create a GitHub repository. Upload the contents of this folder so that `index.html` is at the root alongside `style.css`, `story.js`, `app.js`, and `assets/`.
2. Open **Settings → Pages**. Under **Source**, choose **Deploy from a branch**.
3. Select **main** and **/(root)**, then save. GitHub displays the URL after the deployment finishes.

No build, server, credentials, or external social accounts are required. Your activity is stored in your browser, on that particular site origin. Publishing with standard GitHub Pages makes the fictional scenario and the protagonist's name accessible to people with the site URL. For private play, open the app locally.
